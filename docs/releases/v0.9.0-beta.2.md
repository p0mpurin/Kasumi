The first public beta of Kasumi, a GeForce NOW client for the New 3DS.

- Stream your GeForce NOW library with smooth, frame-paced 30 FPS video
- Library with box art, All / Favourites / Recent tabs and a page for every game
- Per-game options: bitrate, gyro aim and button layout
- Stream menu: screenshots, zoom zones, controls sheet, gyro and sound
- Connection check, five colour themes and a first-run guide
- New HOME Menu icon and banner
- Updates itself from GitHub from now on (Settings > Updates)

Install Kasumi.cia with FBI, or copy Kasumi.3dsx to sdmc:/3ds/.
Needs a New 3DS, New 3DS XL or New 2DS XL with custom firmware.
