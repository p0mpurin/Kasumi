Kasumi 1.1.2: GeForce NOW games start again.

- Since October 27, every GeForce NOW launch got stuck at "waiting for SDP offer", tried to reconnect twice and ended with a session problem. NVIDIA changed which game server it gives to apps like Kasumi, and the one it gave could never start the stream. Kasumi now asks for the right kind of server, and games start as before, with the same picture quality
- Free accounts may now see a queue ad step. Kasumi can't show the ad, tells NVIDIA so the same way the official web client does, and the queue carries on
- Clearer diagnostic reports: a normal exit no longer reads like a failed launch, and reports show which kind of game server NVIDIA assigned

Update from Settings > Updates, or install Kasumi.cia with FBI. Homebrew Launcher users can replace Kasumi.3dsx. Your login, library and settings are kept.
