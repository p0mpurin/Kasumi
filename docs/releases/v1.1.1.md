Kasumi 1.1.1: Steam Link no longer waits forever for a picture.

- Some PCs sent sound but never started the video, so Kasumi sat on "Starting the stream". Kasumi now notices after 20 seconds, tries again by itself with simpler stream settings, and tells you if the PC still sends no picture
- More Steam Link details in diagnostic reports, to find out why a PC doesn't start the video. If this happens to you, please send a report from Settings > System
