Faster reconnects and a live ping reading.

- Faster reconnects: Kasumi now signs back in to the same session as the same client, so NVIDIA can hand the stream straight back. If NVIDIA stays silent it tries again after 12 s instead of 30 s
- Live ping: PING MS in the stream stats used to be measured once while connecting and then never change. It now updates every 2 seconds
- The 3DS always turns Wi-Fi off when the lid closes (the system refuses to keep it on), so closing the lid mid-game still means a reconnect on opening; Kasumi waits for Wi-Fi and then reconnects on its own
