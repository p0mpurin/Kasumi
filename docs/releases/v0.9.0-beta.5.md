Fixes the CIA crashing at start-up (beta.4) and when a stream starts (beta.3).

- Fixed: the installed CIA could not start the audio driver and crashed. The CIA now maps the audio hardware memory it needs, and Kasumi checks for it before starting audio, so a missing mapping means no sound instead of a crash
- Includes everything from beta.4: resume after a crash, queue alert, Continue, QR install

If beta.4 crashes when you open it, install this version with FBI (Remote Install > Scan QR Code, or copy Kasumi.cia to the SD card). Your login, library and settings are kept.
