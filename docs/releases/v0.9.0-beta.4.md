Fixes the crash when a stream starts, and adds resume, queue alerts and Continue.

- Fixed: Kasumi could crash the moment video started (the audio driver now starts once when Kasumi opens)
- Resume after a crash: if Kasumi closes while your game is still running on the rig, the next start offers to jump back in
- Queue alert: close the lid while you wait in the queue; when the rig is ready the notification light pulses and a chime plays
- Continue: your last game sits at the top of the library, one tap or START to play it again
- QR code install: scan it with FBI (Remote Install > Scan QR Code) to install Kasumi straight from GitHub

Update from Settings > Updates, or install Kasumi.cia with FBI.
